This is a repo for calculating feasibility of blue imaging in our clock setup. More to come.

`Polarizability_and_StarkShift.ipynb` compares two ways of imaging one 171Yb tweezer array next to the clock array:
- 399 nm (blue, 1S0-1P1): both arrays in 460.862 nm tweezers
- 556 nm (green, 1S0-3P1): the imaging array in 780 nm tweezers, the clock array in 460.862 nm tweezers. The different tweezers shift the 556 nm resonance differently, so the clock atoms sit far off resonance from the imaging light.
